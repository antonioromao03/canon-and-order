# Data license

The gold set in `gold/` (the annotation guide, template and every file in
`gold/universes/`) is licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/).

Gold files record facts (titles, release dates, episode numbers) and short snippets from
cited sources, some of which are Wikipedia articles licensed CC BY-SA. Each gold entry
keeps the URL of every source it relies on, which serves as attribution.
